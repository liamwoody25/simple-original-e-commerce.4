# Tektronics

## Project Description
I built this simple e-commerce project where the user can choose a product of their choice from the most popular tech, or they can view the latest deal.

---

### Built with:
+ Semantic HTML5
+ CSS3 styling
+ JavaScript (ES6+)

### Features:
+ **Shopping Bag** added the cart icon that opens the hidden shopping bag to store the products when the product is clicked on.
+ **button interaction** made the product buttons transition when the user hovers over the product button.
+ **Bag Controls** I included product quantity controls so users can add or remove products from the shopping bag.
+ **Navigation menu** I added the hamburger menu to display the navigation links.

### What I've Learned

I built this project to practice using JavaScript Arrays and Objects from what I've learned. I also learned about HTML custom data attributes and how they work, and also how JavaScript accesses the data that is set from html.

I also wanted to improve my understanding of using the event listener and how it works with the product buttons when they are clicked. I also wanted to improve my understanding of using the DOM and how it works with the HTML elements to practice using the template literals.
