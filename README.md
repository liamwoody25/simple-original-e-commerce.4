# Tektronics

## project description
I built this simple e-commerce project where the user can choose a product of their 
choice from the most popular tech or they can view the latest deal.

### Technologies:
Html5 semantics, Css3 styling, JavaScript (es6+)

### Features:
+ added the cart icon that opens the hidden wt shopping bag to store the products when the product is clicked on.
+ made the product buttons transition when the user hovers over the product button.
+ I included a product quantity controls so users can add or remove products from the shopping bag
+ I added the hamburger menu to display the navigation links

I built this project to practice using JavaScript Arrays and Objects from what I've learned. I also about HTML custom data attributes and how they work also how JavaScript accesses the data that is set from html
