# Tektronics

## project description
I built this simple e-commerce project where the user can choose a product of their 
choice from the most popular tech or they can view the latest deal.

### Technologies:
+ Html5 semantics, 
+ Css3 styling, 
+ JavaScript (es6+)

### Features:
+ I added the cart icon and made the shopping bag hidden to store the products when the product is clicked on.
+ made the product buttons transition when they are being hovered over.
+ I included a product quantity so the user can add or remove products from the shopping bag
+ added a hamburger menu to display the navigation links
